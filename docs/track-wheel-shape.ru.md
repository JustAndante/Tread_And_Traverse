# Форма по колёсам

<figure class="doc-figure">
  <img src="{{ '/assets/images/track/wheel-shape.svg' | relative_url }}" alt="Переднее и заднее крайние колёса, опорные катки и верхние ролики">
  <figcaption>Сначала сопоставьте роли колёс с костями рига, затем настраивайте радиусы обвода.</figcaption>
</figure>

Здесь задаётся исходный контур гусеницы. Сначала добейтесь правильной формы без
контакта с землёй и только затем настраивайте поверхность.

## Подготовьте кости

1. Используйте последовательные имена опорных катков.
2. Задайте отдельные префиксы для левой и правой стороны.
3. Укажите крайние колёса и поддерживающие ролики отдельно.
4. Runtime обновит controls автоматически. При собственном расписании вызовите
   `Generate Controls From Wheel Rig` после изменения имён, количества или
   порядка костей.

## Проверьте радиусы

- Радиус в Solver описывает геометрию контакта колеса со сплайном.
- Скорость звеньев берётся из выбранного источника привода и Chaos wheel radius,
  а не из геометрического радиуса Solver.
- Добавляйте поддерживающий ролик только там, где верхняя ветвь действительно
  должна иметь опору.

## Результат

- контур проходит по ожидаемой стороне каждого колеса;
- левая и правая стороны симметричны;
- крайние переходы не имеют резких изломов;
- изменение подвески двигает контур без смены количества точек.
