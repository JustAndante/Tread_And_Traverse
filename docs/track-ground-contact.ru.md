# Контакт с поверхностью

<figure class="doc-figure">
  <img src="{{ '/assets/images/track/ground-contact.svg' | relative_url }}" alt="Центральные и боковые probes нижней ветви ищут World Static">
  <figcaption>Одна ширина контакта управляет областью поиска под башмаком; фильтр определяет допустимые поверхности.</figcaption>
</figure>

Цель — дать поверхности выталкивать гусеницу наружу, не превращая корпус танка
или случайные компоненты в опору.

## Безопасная база

1. Оставьте `Surface Query Mode = World Static Only`.
2. Убедитесь, что земля отвечает на выбранные object types.
3. Начните с ровной поверхности.
4. Затем проверьте мелкие неровности и только после этого острые переходы.

## Ширина и смещение

- `Track Contact Width` — единственная рабочая ширина проверки.
- Увеличивайте её только если узкая проверка пропускает край дороги.
- Контактное смещение компенсирует толщину башмака; оно не должно использоваться
  для исправления неправильной формы по колёсам.

## Результат

- гусеница реагирует на пол, но не на корпус и оружие машины;
- на ровной поверхности нет переключения между конкурирующими hits;
- на мелкой неровности контур меняется плавно;
- после отрыва колеса прежний hit не удерживает гусеницу.
