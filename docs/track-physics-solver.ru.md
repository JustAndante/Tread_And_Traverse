# Track Spline Builder

Создаёт замкнутую визуальную гусеницу по костям ходовой, деформирует её по
подвеске и поверхности и размещает звенья с постоянным количеством.

<div class="guide-callout" markdown="1">
**Рекомендуемый путь:** сначала соберите одну сторону по разделу ниже. Когда она
работает в PIE, скопируйте компоненты на вторую сторону и поменяйте только имена
костей, направление и визуальные меши.
</div>

<a id="quick-start"></a>

## Быстрый старт

### 1. Подготовьте Actor машины

Для каждой стороны добавьте:

- один `Spline Component`;
- один `Track Spline Builder`;
- один `Track Physics Solver`.

В Skeletal Mesh должны существовать последовательно названные кости опорных
катков. Крайние и поддерживающие колёса можно указать отдельно.

### 2. Настройте визуальные звенья

В `Track Spline Builder`:

1. Выберите созданный сплайн в `Source Spline`.
2. Назначьте `Track Link Mesh` и, если используется, меш коннектора.
3. Задайте фиксированное число звеньев или шаг.
4. Оставьте `Orientation Mode = Planar Track` для обычной танковой гусеницы.

### 3. Постройте контур по колёсам

В `Track Physics Solver`:

1. Выберите тот же сплайн в `Target Spline`.
2. Укажите `Source Mesh Component`.
3. Задайте префикс костей опорных катков и кости крайних колёс.
4. Проверьте радиусы контакта колёс.
5. Нажмите `Generate Bone Rig Now`.

### 4. Свяжите Solver и Builder

1. Выберите соответствующий `Track Builder`.
2. Включите `Update Track Builder After Solve`.
3. Нажмите `Validate Setup`.
4. Исправьте ошибки, пока конфигурация не станет готовой.

### 5. Проверьте в PIE

Рабочий результат:

- контур замкнут;
- число звеньев не меняется;
- звенья распределены равномерно;
- направление и скорость совпадают с движением машины;
- гусеница реагирует на поверхность, но не на корпус танка;
- на dedicated server не считается дорогая визуальная физика, если она не нужна.

Для обычной машины оставьте `Surface Query Mode = World Static Only`.

## Форма по колёсам

- Используйте стабильную схему имён костей и отдельные префиксы для левой и
  правой стороны.
- Радиус в Solver описывает геометрию контакта. Скорость движения звеньев
  берётся из выбранного источника привода и Chaos wheel radius.
- После изменения количества, имён или порядка костей повторно выполните
  `Generate Bone Rig Now`.
- Если верхняя ветвь должна провисать, добавьте поддерживающие ролики только там,
  где гусеница действительно должна иметь опору.

Полные поля: [источник геометрии и колёса]({{ '/docs/track-settings-reference.ru.html#geometry-source' | relative_url }}).

<a id="ground"></a>

## Контакт с поверхностью

- Начинайте с `World Static Only`: корпус, оружие и другие компоненты машины не
  должны формировать поверхность гусеницы.
- `Track Contact Width` задаёт рабочую ширину проверки. Увеличивайте её только
  если узкая трассировка пропускает край дороги.
- Сначала проверяйте форму на ровной поверхности, затем на мелких неровностях и
  только после этого — на острых переходах.
- При дрожании в покое убедитесь, что коллизия пола стабильна, а Solver не
  переключается между несколькими конкурирующими поверхностями.

Полные поля: [трассировка поверхности]({{ '/docs/track-settings-reference.ru.html#surface-tracing' | relative_url }}).

<a id="links"></a>

## Звенья и движение

- Для танковой гусеницы используйте фиксированное число звеньев. Деформация
  сплайна не должна создавать или удалять экземпляры.
- `Reverse Track Direction` — ручной переключатель направления.
- Источник вращения, ось и совместимость знака настраиваются в группе привода.
  Не исправляйте знак отрицательным масштабом скорости.
- Меш звена должен иметь согласованную локальную ось и pivot. Если часть звеньев
  переворачивается, сначала проверьте ориентацию меша, затем режим ориентации.
- Коннектор должен использовать ту же материальную фазу, что и связанная пара
  звеньев.

Все вызываемые действия и runtime-переключатели: [Blueprint-ноды]({{ '/docs/track-blueprint-nodes.ru.html' | relative_url }}).

<a id="quality"></a>

## Качество и сеть

- `Full Physical` используйте для локальной или близкой машины.
- `Cheap Remote` сохраняет визуальный контур без дорогой физической цепи.
- `Local Ownership + Distance` позволяет каждому клиенту выбирать стоимость
  самостоятельно; это косметическое состояние не реплицируется.
- `External` выбирайте, если проект сам управляет качеством через Blueprint.
- На dedicated server визуальную гусеницу обычно отключают.

Полные поля: [Simulation и Runtime]({{ '/docs/track-settings-reference.ru.html#simulation-runtime' | relative_url }}).

<a id="troubleshooting"></a>

## Быстрая диагностика

| Симптом | Сначала проверьте |
| --- | --- |
| Контур не появился | `Target Spline`, `Source Mesh Component`, имена костей и результат `Validate Setup`. |
| Левая и правая стороны идут в разные стороны | `Reverse Track Direction`, ось вращения и compatibility sign matching. |
| Скорость не совпадает с машиной | Источник вращения, соответствующее Chaos wheel и его реальный radius. |
| Гусеница реагирует на корпус | `Surface Query Mode = World Static Only` и collision profile поверхности. |
| Звенья переворачиваются | Локальные оси/pivot меша и `Orientation Mode`. |
| Расстояние между звеньями гуляет | Фиксированное число звеньев, замкнутый сплайн и отсутствие смены topology. |
| Дрожание в покое | Стабильность ground hit, конкурирующие поверхности и частоту решения. |

Если симптом требует точного поля, используйте поиск слева по всему разделу
плагина или откройте [полный справочник настроек]({{ '/docs/track-settings-reference.ru.html' | relative_url }}).
