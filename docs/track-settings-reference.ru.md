# Track Spline Builder: справочник настроек

Здесь перечислены все поддерживаемые поля компонентов без сокращений. Для
первой установки и решения типовых задач используйте
[короткое руководство]({{ '/docs/track-physics-solver.ru.html' | relative_url }}).
Вызываемые действия находятся в отдельном
[справочнике Blueprint-нод]({{ '/docs/track-blueprint-nodes.ru.html' | relative_url }}).

<a id="solver-settings"></a>

## Настройки компонентов

Названия ниже совпадают с панелью Details в Unreal Engine. Значения являются
исходными значениями класса; runtime не перенастраивает редактируемые поля
скрытно. Если не указано иное, расстояния заданы в сантиметрах Unreal.

## Output: целевой сплайн

| Параметр | По умолчанию | Назначение |
| --- | ---: | --- |
| `Target Spline` | None | Имя компонента сплайна, в который записывается рассчитанный замкнутый контур гусеницы. Укажите тот же сплайн, который использует соответствующий `Track Spline Builder`. |

<a id="geometry-source"></a>

## Setup: источник геометрии

| Параметр | По умолчанию | Назначение |
| --- | ---: | --- |
| `Closed Loop` (Advanced) | On | Соединяет первую и последнюю рассчитанные точки. Непрерывная танковая гусеница должна оставаться замкнутой. |
| `Generate From Bone Rig` | On | Строит полный контур управляющих точек по костям опорных катков, поддерживающих роликов и концевых колёс. Для релизной настройки машины оставляйте параметр включённым. |
| `Source Mesh Component` | None | Skeletal Mesh или Scene Component, содержащий настроенные кости колёс. Он же служит достоверным источником движения подвески во время симуляции. |
| `Auto Detect Wheel Counts` | On | Ищет последовательно пронумерованные кости и останавливается после окончания ряда опорных катков или верхних роликов. |
| `Wheel Auto-Detection Limit` (Advanced) | 32 | Максимальное число индексов, проверяемых для каждого префикса опорных катков и верхних роликов. Видно только при автоматическом определении количества. |

### Сгенерированные и сохранённые данные (только чтение)

Эти поля находятся рядом с настройками источника, но принадлежат самому
решателю и не являются обычными пользовательскими параметрами.

| Поле | Что означает |
| --- | --- |
| `Control Points` | Описания управляющих точек, по которым строится желаемый контур. В обычном процессе массивом управляет генератор по костям. |

## Setup: опорные катки

| Параметр | По умолчанию | Назначение |
| --- | ---: | --- |
| `Road Wheel Prefix` | `LM_Wheel_` | Текст перед числовым индексом кости опорного катка. Задаётся явно для каждой стороны гусеницы. |
| `Road Wheel Suffix` | Пусто | Текст после числового индекса. Оставьте пустым для имён вида `LM_Wheel_01`; суффикс нужен только тогда, когда он присутствует в риге. |
| `First Road Wheel Index` | 1 | Индекс первой кости опорного катка в последовательности. |
| `Road Wheel Count` | 7 | Количество опорных катков при ручной настройке. Видно только при выключенном `Auto Detect Wheel Counts`. |
| `Road Wheel Index Digits` (Advanced) | 2 | Минимальное количество цифр в индексе. Значение 2 создаёт имена с `01`, `02` и далее. |
| `Trace Ground Between Road Wheels` | On | Выполняет трассировку поверхности для нижних промежуточных точек между центрами соседних опорных катков. Выключайте только для жёсткой или чисто интерполированной нижней ветви. |
| `Road Wheel Contact Radius` | 39 cm | Радиус только для формы solver и контакта с катком. Скорость движения звеньев отдельно рассчитывает `Track Spline Builder` по runtime-радиусу выбранного Chaos wheel. |

## Setup: поддерживающие ролики

Все дочерние параметры этого раздела скрываются при выключенном
`Generate Top Rollers`.

| Параметр | По умолчанию | Назначение |
| --- | ---: | --- |
| `Generate Top Rollers` | On | Включает настроенные поддерживающие ролики в создаваемую верхнюю ветвь. |
| `Top Roller Bone Prefix` (Advanced) | `TopWheel` | Текст перед числовым индексом кости верхнего ролика. |
| `Top Roller Bone Suffix` (Advanced) | `_L` | Текст после индекса. Задаётся явно, если стороны используют разные суффиксы. |
| `First Top Roller Index` | 1 | Индекс первой кости верхнего ролика. |
| `Top Roller Count` | 4 | Количество верхних роликов при ручной настройке. Видно только при выключенном автоматическом определении количества. |
| `Top Roller Index Digits` (Advanced) | 2 | Минимальное количество цифр при составлении имён костей верхних роликов. |
| `Top Roller Contact Radius` | 22 cm | Радиус, по которому гусеница огибает верхний ролик и соблюдает одностороннее ограничение его окружности. |
| `Allow Top Roller Detach` | Off | Разрешает верхним точкам отходить от точного положения кости, сохраняя ограничение радиусом. Верхняя ветвь получает возможность реагировать на удары и инерцию подвески. |
| `Top Run Physics` | On | Включает физическую симуляцию верхней возвратной ветви. Выключение оставляет более дешёвую процедурную форму. |
| `Upper Run Physics Weight` (Advanced) | 0.45 | Сила физического движения и инерции для отсоединённых верхних точек. Видно только при одновременно включённых верхней физике и отсоединении. |
| `Detached Upper Travel Limit` (Advanced) | 18 cm | Максимальное отклонение отсоединённых верхних точек от созданной формы. Значение 0 отключает это ограничение. |
| `Speed Tension` | Off | Уменьшает провисание верхней ветви с ростом скорости машины, не меняя нижнюю контактную форму. Точная реакция задаётся его дочерними полями. |

## Setup: концевые колёса

Раздел `End Wheels` охватывает переднее направляющее или концевое колесо и
заднее ведущее колесо. Это условные механические роли: на другой машине ведущим
может быть любой конец, если кости, радиусы и порядок контура настроены верно.

| Параметр | По умолчанию | Назначение |
| --- | ---: | --- |
| `Generate End Wheels` | On | Строит переднюю и заднюю дуги концевых колёс, соединяющие верхнюю и нижнюю ветви. |
| `Front End Wheel Bone` | `LF_Wheel_00` | Кость, используемая как центр передней дуги обвода. |
| `Rear Drive Wheel Bone` | `LB_Wheel_08` | Кость центра задней дуги и, по умолчанию, источник дистанции прокрутки визуальной гусеницы. |
| `Front End Wheel Wrap Radius` | 55 cm | Радиус дуги центра трака вокруг переднего концевого колеса. |
| `Rear Drive Wheel Wrap Radius` | 0 cm | Радиус заднего ведущего колеса. Значение 0 использует `Front End Wheel Wrap Radius`. |
| `Wrap Points Per End Wheel` | 3 | Количество основных управляющих точек на каждой концевой дуге. Большее значение точнее описывает окружность, но увеличивает объём расчёта. |
| `End Wheel Wrap Arc` (Advanced) | 130 degrees | Угловая длина части окружности, используемой для построения обвода каждого концевого колеса. |
| `End Wheel Wrap Angle Offset` (Advanced) | 0 degrees | Поворачивает обе дуги вокруг центров колёс, позволяя совместить переходы с конкретным ригом. |

## Setup: детализация формы

| Параметр | По умолчанию | Назначение |
| --- | ---: | --- |
| `Generate Detail Points By Spacing` | On | Добавляет промежуточные точки на длинных участках, чтобы плотность зависела от заданного расстояния, а не только от количества основных точек колёс. |
| `Target Detail Point Spacing` | 35 cm | Желаемый максимальный шаг промежуточных точек. Меньшее значение создаёт более плотный и более дорогой сплайн. |
| `Maximum Detail Points Per Segment` (Advanced) | 6 | Защитный предел количества автоматически создаваемых точек между двумя соседними основными контролами. |
| `Trace Generated Detail Points` | On | Разрешает промежуточным точкам искать поверхность, а не только интерполироваться между основными контролами. Важно для ступеней и препятствий между катками. |
| `Unsupported Span Sag Ratio` | 0.08 | Глубина провиса как доля длины неподдерживаемого участка. Также масштабирует слабину физической цепи и предел дополнительного провиса, поэтому крупные изменения влияют и на желаемую форму, и на физическую реакцию. |

<a id="surface-tracing"></a>

## Setup: трассировка поверхности

| Параметр | По умолчанию | Назначение |
| --- | ---: | --- |
| `Surface Query Mode` | World Static Only | Выбирает единый collision-фильтр для созданных ground trace, sweep физической цепи и runtime overlap broadphase. `World Static Only` исключает корпус машины, Pawn и подвижный мусор сцены без обязательного проектного collision channel. |
| `Surface Object Types` | Пусто | Типы объектов, принимаемые в режиме `Object Types`. Заполните список для подвижных платформ и проектных object channel. Пустой список намеренно отключает попадания по поверхности в этом режиме. |
| `Surface Trace Channel` | Visibility | Канал, используемый только в режиме `Trace Channel`. Этот режим совместимости или пользовательской настройки принимает любой компонент, блокирующий выбранный канал. |
| `Enable Ground Tracing` | On | Разрешает созданным точкам с включённым trace находить поверхности мира и формировать контакты нижней ветви. |
| `Snap Trace Points To Ground` | On | Помещает принятую точку прямо на результат контакта. При выключении используется `Ground Alignment Strength` для более мягкого сближения. |
| `Ground Trace Length` | 350 cm | Полная длина поиска вниз для автоматически созданных trace-точек. |
| `Ground Trace Start Height` | 120 cm | Высота начала трассировки над созданной точкой. |
| `Track Contact Width` | 0 cm | Единая полная ширина для созданных probes и runtime-контакта. Значение 0 использует только центральный probe; иначе задайте примерно физическую ширину башмака. |
| `Ground Trace Shape` (Advanced) | Sphere | `Line` использует луч нулевого радиуса. `Sphere` выполняет sweep заданного радиуса и лучше переносит мелкие щели и резкие детали меша. |
| `Ground Trace Radius` (Advanced) | 3 cm | Радиус сферы при выбранной форме `Sphere`. |
| `Ground Alignment Strength` (Advanced) | 0.35 | Сила сближения с принятой поверхностью, когда прямое прилипание `Snap Trace Points To Ground` выключено. |
| `Maximum Ground Snap Distance` (Advanced) | 26 cm | Отклоняет контакт, если для его принятия точку нужно переместить дальше этого расстояния. Защищает от захвата далёкой или посторонней поверхности. |
| `Maximum Ground Search Drop` (Advanced) | 90 cm | Отклоняет поверхность, найденную слишком низко относительно созданной точки, даже если она находится внутри полной длины trace. |

`Ground Trace Length` определяет, где решатель может искать поверхность.
`Maximum Ground Snap Distance` и `Maximum Ground Search Drop` определяют,
какой найденный результат разрешено принять. Эти параметры решают разные
задачи и не заменяют друг друга.

Фильтр поверхности влияет только на визуальный решатель гусеницы и не меняет
коллизии Chaos-машины. Если гусеница должна повторять подвижную платформу или
другую явно настроенную поверхность, выберите `Object Types` либо
`Trace Channel`; в остальных случаях оставьте предпродажный дефолт
`World Static Only`.

## Дополнительный компонент Track Physics Diagnostics

Debug-настройки намеренно отсутствуют в обычной панели Details решателя.
Для поиска конкретной проблемы временно добавьте editor-only компонент
`Track Physics Diagnostics` и выберите нужный solver. В cooked build этот
компонент не попадает.

| Параметр | По умолчанию | Назначение |
| --- | ---: | --- |
| `Draw Debug` | Off | Включает визуализацию решателя в редакторе или PIE. Для обычной игры и измерения производительности оставляйте выключенным. |
| `Detailed Runtime Diagnostics` | Off | Собирает долговременные пики ограничений, целей, выходных точек и снимки стадий расчёта. Включайте только для направленной диагностики: режим копирует массивы и усложняет формирование строк статуса. |
| `Draw Debug Traces` | On | Рисует probes поверхности и результаты попадания или промаха при включённом `Draw Debug`. |
| `Draw Debug Points` | On | Рисует желаемые, фиксированные, контактные и физические точки. |
| `Draw Debug Solved Spline` | On | Рисует окончательный рассчитанный контур. |
| `Draw Debug Wheel Guides` | On | Рисует окружности колёс, принадлежность guide-точек и срабатывания радиусных ограничений. |
| `Debug Draw Interval` (Advanced) | 0.1 s | Минимальный интервал между обновлениями отладочной отрисовки. Не меняет частоту работы самого решателя. |
| `Debug Point Size` (Advanced) | 8 cm | Размер маркеров отладочных точек. |
| `Debug Line Thickness` (Advanced) | 1.5 | Толщина отладочных линий. |
| `Debug Anchor Color` | Cyan | Цвет фиксированных и исходных anchor-точек. |
| `Debug Solved Color` | Yellow | Цвет рассчитанного сплайна. |
| `Debug Trace Hit Color` | Green | Цвет успешных трассировок. |
| `Debug Trace Miss Color` | Red | Цвет неуспешных трассировок. |
| `Debug Wheel Guide Color` | Purple | Цвет геометрии wheel guide. |
| `Debug Wheel Limit Color` | Magenta | Цвет коррекций односторонних ограничений колёс. |

## Поля диагностического лога (внутренние)

Это внутренние диагностические данные solver, а не обычные настройки. Компонент
диагностики собирает нужные значения в одно поле `Copy-Ready Diagnostic Log`.

### Основной статус

| Поле | Что означает |
| --- | --- |
| `Last Solver Status` | Читаемая сводка последней генерации, расчёта, контактов, физического режима, обновления Builder и ключевых диагностических значений. |
| `Last Validation Status` | Результат последней проверки настройки: отсутствующий сплайн, источник, Builder или ошибки геометрии. |
| `Last Debug Snapshot` | Последний подробный снимок диагностики. Точная атрибуция пиков требует включённого `Detailed Runtime Diagnostics`. |
| `Last Desired Point Count` | Количество точек, созданных стадией желаемой формы. |
| `Last Solved Point Count` | Количество точек в окончательном расчёте. Обычно должно совпадать с желаемым количеством. |
| `Last Missing Source Count` | Количество контролов, для которых не удалось найти компонент, кость или socket. В норме — 0. |
| `Last Ground Contact Count` | Количество желаемых точек, которые сейчас приняты как контакты с поверхностью. |
| `Last Matched Wheel Points` | Количество созданных точек, успешно сопоставленных с костями и guide-окружностями колёс. |
| `Last Generated Control Point Count` | Количество основных контролов после последней генерации. |
| `Last Skipped Endpoint Wheels` | Концевые кости, намеренно исключённые из ряда опорных катков, поскольку ими управляет генератор концевых колёс. |
| `Last Desired Extent` | Примерный пространственный размер созданного контура, используемый проверкой и диагностикой. |
| `Last Bad Segment Count` | Количество сегментов, отклонённых защитой от плохой геометрии. В норме — 0. |
| `Last Max Segment Length` | Самый длинный сегмент последнего рассчитанного контура. Неожиданный пик указывает на сломанную топологию или скачок точки. |

### Контакты и процедурная форма (Advanced)

| Поле | Что означает |
| --- | --- |
| `Last Fixed Support Count` | Количество желаемых точек, считающихся фиксированными или исходными опорами. |
| `Last Suspended Support Count` | Опоры, ограничивающие неподдерживаемые участки провиса. |
| `Last Suspended Span Count` | Неподдерживаемые участки, получившие процедурный провис. |
| `Last Trace Penetration Recoveries` | Начальные пересечения, восстановленные специальной веткой penetration recovery. |
| `Last Trace Rejected Initial Penetration Count` | Небезопасные trace-результаты с начальным пересечением, которые были отклонены. |
| `Last Trace Rejected Far Drop Count` | Попадания, отклонённые параметром `Maximum Ground Search Drop`. |
| `Last Trace Rejected Max Snap Distance Count` | Попадания, отклонённые параметром `Maximum Ground Snap Distance`. |
| `Last Ground Contact Hysteresis Hold Count` | Существующие контакты, временно удержанные гистерезисом, чтобы не допустить дребезга опор. |
| `Last Merged Generated Duplicate Count` | Дублирующиеся точки, удалённые при генерации по костям. |
| `Last Merged Runtime Point Count` | Близкие промежуточные точки, объединённые при построении желаемой формы во время игры. |
| `Last Effective Detail Scale` | Фактический множитель шага детализации; обычно 1 в режиме Full Physical. |
| `Last Effective Trace Fan Count` | Фактическое число боковых probes после применения выбранного режима качества. |
| `Last Trace Fallback Hit Count` | Контакты, принятые от запасного probe вместо основного. |
| `Last Trace Memory Hit Count` | Контакты, восстановленные из недавней памяти trace той же точки. |
| `Last Trace Nearest Memory Hit Count` | Контакты, восстановленные из совместимой записи памяти соседней точки. |
| `Last Trace Detail Point Count` | Общее число промежуточных точек, выполнивших trace. |
| `Last Lower Trace Detail Point Count` | Trace-точки, относящиеся именно к нижней ветви. |

### Физическая цепь (Advanced)

| Поле | Что означает |
| --- | --- |
| `Last Average Physics Weight` | Средний фактический вес симуляции динамических точек. |
| `Last Dynamic Point Count` | Количество точек, которым разрешено физически двигаться. |
| `Last Effective Pinned Point Count` | Количество точек, фактически закреплённых после применения runtime-качества. |
| `Last Effective Physical Target Pull` | Фактическая сила притяжения к созданной форме в текущем режиме. |
| `Last Effective Wheel Surface Guide Strength` | Фактическая сила следования поверхности колёс после overrides runtime-качества. |
| `Last Owner Carry Distance` | Смещение transform владельца, перенесённое в симуляцию на последнем обновлении. |
| `Last Owner Inertia Speed` | Фактическая скорость инерции движения владельца, применённая к свободным точкам. |
| `Last Sag Limit Correction Count` | Количество точек, скорректированных ограничением дополнительного провиса. |
| `Last Physical Velocity Clamp Count` | Количество ограничений скорости точек защитным максимумом. |
| `Last Physical Constraint Clamp Count` | Количество коррекций constraints, ограниченных защитным максимумом. |

## Simulation: физическое поведение

| Параметр | По умолчанию | Назначение |
| --- | ---: | --- |
| `Solver Mode` (Advanced) | Physical Chain | Выбирает алгоритм расчёта формы. Это не политика выбора качества для разных зрителей. |
| `Chain Gravity Scale` | 1.0 | Множитель гравитации во время интеграции физической цепи. |
| `Generated Shape Pull` | 0.35 | Притягивает симулируемые точки к желаемой форме. Большее значение лучше контролирует форму; меньшее отдаёт приоритет контактам, constraints и инерции. |
| `Wheel Guide Pull` (Advanced) | 0.10 | Минимальное притяжение к формам верхних и концевых колёс. Отсоединённые верхние точки получают уменьшенную долю. |
| `Per-Segment Slack Ratio` | 0 | Добавляет податливую слабину rest length каждому физическому сегменту. Итоговая слабина также масштабируется `Unsupported Span Sag Ratio`. |
| `Chain Velocity Damping` (Advanced) | 0.15 | Гасит скорость физических точек на каждом шаге. Большие значения быстрее успокаивают движение; чрезмерные делают гусеницу жёсткой. |
| `Preserve Ground Contacts` (Advanced) | On | Сохраняет принятые ground-контакты во время решения constraints вместо немедленного отрыва цепи. |
| `Physical Contact Hold Strength` (Advanced) | 1.0 | Сила сохранения уже принятого физического контакта с землёй. Не управляет выравниванием trace. |
| `Maximum Extra Sag` | 35 cm | Максимальное дополнительное движение вниз относительно процедурной формы неподдерживаемого участка. Значение 0 отключает предел. |
| `Keep Track Outside Wheels` | On | Применяет односторонние радиусные ограничения опорных, верхних и концевых колёс. Не даёт физическим точкам пройти сквозь колесо, но не притягивает уже свободные точки обратно к окружности. |
| `Wheel Clearance` (Advanced) | 0 cm | Единственный дополнительный радиальный зазор для всех ограничений колёс. |
| `Wheel Surface Following` (Advanced) | 0 | Направляет близкие физические точки вдоль окружности после радиусного ограничения. |
| `Traced Point Physics Weight` (Advanced) | 0.2 | Участие в физике точек, созданных ground trace. Не меняет выравнивание trace и силу удержания контакта. |

## Runtime

| Параметр | По умолчанию | Назначение |
| --- | ---: | --- |
| `Solve Track On BeginPlay` | On | При необходимости создаёт controls, после заданной задержки решает сплайн и обновляет связанный Builder. |
| `Manual / Fallback Quality` | Full Physical | Используется напрямую политикой `Manual` и как безопасный fallback, пока `External` не получил значение. `Full Physical` запускает штатный traced solver, `Cheap Remote` оставляет дешёвую процедурную форму, `Advanced Material Track` включает постоянную material-chain отрисовку. |
| `Quality Selection` | Manual | `Manual` ничего не переопределяет. `Local Ownership` назначает локальное качество Pawn, которым управляет локальный игрок, и remote-качество остальным. `Local Ownership + Distance` дополнительно делит чужие Pawn на ближние и дальние по ближайшей локальной камере. `External` принимает явное локальное решение из Blueprint/C++. |
| `Locally Controlled Quality` | Full Physical | Качество Pawn под управлением локального человеческого Player Controller. AI-контроллер не считается локальным игроком. |
| `Remote / Near Quality` | Cheap Remote | Качество нелокальных Pawn в `Local Ownership` или ближних нелокальных Pawn в distance-политике. |
| `Remote Far Quality` | Cheap Remote | Качество, которое distance-политика использует для дальних нелокальных Pawn, а также на клиенте или dedicated server без корректной локальной камеры. В `Local Ownership` все нелокальные Pawn используют `Remote / Near Quality`. |
| `Remote Near Distance` | 5000 cm | Расстояние от камеры, разделяющее ближние и дальние чужие Pawn. Каждый клиент вычисляет его независимо. |
| `Distance Hysteresis` | 500 cm | Не даёт качеству постоянно переключаться около границы расстояния. |
| `Selection Update Interval` | 0.25 s | Частота повторной проверки владения и расстояния. После мгновенной смены possession или камеры вызовите `Refresh Runtime Quality Selection`. |
| `Lower Shoe Tangent Scale` | 0.55 | Длина tangent нижнего участка башмаков в режиме Cheap Remote. |
| `Lower Transition Tangent Scale` | 0.35 | Длина tangent в месте перехода нижней ветви к концевой дуге в Cheap Remote. |
| `BeginPlay Rebuild Delay` (Advanced) | 0.2 s | Задержка запланированного перестроения после BeginPlay. Даёт Skeletal Mesh и vehicle-компонентам время на инициализацию. |
| `Regenerate Controls On BeginPlay` | On | Перед BeginPlay-rebuild заново создаёт контролы из костей ходовой. Оставляйте включённым для обычной релизной настройки. |
| `Update Every Tick` | On | Включает непрерывный runtime-расчёт. Компонент всё равно соблюдает `Solve Interval`. |
| `Solve Interval` (Advanced) | 0.033 s | Минимальное время между расчётами. 0 означает расчёт каждый Tick; большие значения уменьшают нагрузку и частоту реакции. |
| `Max Solve Delta Time` (Advanced) | 0.05 s | Максимальный временной шаг одного расчёта. Более длинные накопленные кадры ограничиваются, защищая физику от резкого скачка. |

Выбор качества намеренно локальный и не реплицируется. Поэтому каждый игрок
может выбрать подходящую стоимость отрисовки, не меняя авторитетное состояние
машины. Для полного контроля со стороны проекта выберите `External` и вызывайте
`Set External Runtime Quality`; `Clear External Runtime Quality` возвращает
`Manual / Fallback Quality`.
